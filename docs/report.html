Before you write

  • Search the open issues first. If yours is there, add a thumbs up or a comment.
  • Check the questions and the runbook.
  • One problem per report makes it faster to fix.

What helps

Which screen
Today, Openings, Opening page, Drill, Traps, Shared game, Pro, Settings, Backup or Other.
App version
Settings, About Chess Pass.
Phone model and Android version
Android settings, About phone.
For a wrong line or note
The opening, the line, the move, and what you think is wrong.
Steps
What you did, one step per line, so we can do the same.
Expected and actual
What you thought would happen, and what happened.
A picture
A screenshot or a short description.

Issues on GitHub are public. Do not write your name, address or anything else private in a report, and check a screenshot before you attach it.

Other ways
